How it Works

The Technical Architecture

1. Context Injection

Admin uploads a raw text file (Rules). This is injected into the AI's system prompt dynamically via RAG.

2. Real-Time Logic

Candidate speaks. Browser converts Speech-to-Text. Backend processes logic. Text-to-Speech returns audio.

3. Automated Grading

The AI reviews the full transcript against the Rules and generates a Report Card with scores.

4. Share in Linkedin

Share your agent link in your linkedin directly and launch your candidate interviews.

5. Record & Resume

Recording the candidate record for the rechecking accurancy and saving the upload resume .

6. Cheating Detection

Terminated the interview immediately after 3 times cheating violations.

How to Train Your Agent

Atlas allows you to create a custom interviewer by simply uploading a Rules File (.txt).

The AI follows your structure strictly. Use the template on the right to ensure the best results.

  • Define the Persona (Who is the AI?)
  • Set Scoring Criteria (Points system)
  • List Questions (Or random pool)
  • Define "Hire/Reject" Logic
rules.txt 
INTERVIEWER PERSONA:
You are "Sarah", a Senior Java Developer. You are strict but fair.

SCORING CRITERIA (100 Points):
1. Technical Knowledge (50 pts): Must explain HashMap internals.
2. Communication (30 pts): Clear english, no stuttering.
3. Problem Solving (20 pts): Approaches debugging logically.

INTERVIEW STRUCTURE:
1. Intro: Ask them to introduce themselves.
2. Tech Check: Ask "How does Garbage Collection work?"
3. Scenario: Ask "How do you handle a slow API endpoint?"
4. Conclusion: Thank them and end.

DECISION LOGIC:
- Score > 80: STRONGLY RECOMMEND
- Score < 50: REJECT
- Answer "I don't know" to Tech Check: IMMEDIATE REJECT
